# Phase 7: Exploratory Notebooks & Reports

This directory houses notebooks and reports detailing the system architecture, exploratory data analysis (EDA), model training experiments, and final performance evaluations.

## 🎯 Objectives
- **Exploratory Data Analysis (EDA):** Visualize baseline data distributions, log volume patterns, and injected anomalies.
- **Model Evaluation:** Compare performance metrics (Precision, Recall, ROC-AUC) across baseline models, sequence models, and classifiers.
- **Reporting:** Export final performance summaries and presentation slides.
