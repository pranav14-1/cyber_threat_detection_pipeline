# Phase 6: Incident Triage & Explainability Dashboard

This module provides a web-based visualization dashboard for security operations center (SOC) analysts to review, triage, and understand the alerts generated by the pipeline.

## 🎯 Objectives
- **Alert Ingestion Timeline:** Visualize real-time or batched anomalies over time, highlighted by risk severity levels.
- **MITRE Tactics Breakdown:** Provide interactive graphs detailing what attack techniques (e.g., privilege escalation, lateral movement) are active in the system.
- **Explainability Viewport:** Embed interactive SHAP/LIME charts and sequence flow diagrams detailing why a specific log sequence triggered an alert.
- **Feedback Loop:** Enable analysts to mark alerts as False Positives or True Positives to retrain the supervised classifier.

## 🚀 Getting Started
To run the Streamlit dashboard:
```bash
streamlit run app.py
```
